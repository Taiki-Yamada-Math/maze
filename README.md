# 手描き迷路ソルバー

紙に手描きした迷路を写真から読み込み、グラフアルゴリズムが解いていく過程を可視化するウェブアプリです。
`index.html` 一枚で完結しており、ビルドもインストールも不要です。

## 使い方

1. アプリ内の「方眼用紙を印刷する」から用紙を印刷します（21×15マス、四隅に位置合わせマーク付き）。
2. **マス目の線をなぞって塗る**形で壁を描きます。濃い鉛筆やサインペンが読み取りやすいです。
3. 明るい場所で、四隅のマークが4つとも入るように正面から撮影します。
4. 「紙の写真から読み込む」で写真を選ぶと、自動で解析されます。
5. アルゴリズムを選んで「探索して解く」を押します。

青い格子がマス目に、マゼンタが壁に重なっていれば正しく読み取れています。
ズレている場合はオレンジの四隅をドラッグするか、マス数を調整してください。

## アルゴリズム

| | 特徴 |
|---|---|
| 幅優先探索 (BFS) | 波紋状に均等に広がり、最短の歩数を必ず見つける |
| 深さ優先探索 (DFS) | 行けるところまで潜る。速いが最短とは限らない |
| ダイクストラ法 | 優先度付きキューで近い順に確定。最短を保証 |
| A* 探索 | ゴール方向を推定し、無駄な探索を減らす |

通れるマスをノード、壁のない隣接を辺とするグラフに変換して探索します。
BFS/DFS はキューとスタック、ダイクストラと A* は二分ヒープで実装しています。

## 画像認識のしくみ

1. 各画素が周囲の紙面よりどれだけ暗いかを求めます（局所コントラスト）。照明ムラの影響を受けません。
2. 方眼の罫線が作る周期をフーリエ解析で読み取り、マス数を自動決定します。
3. 四隅マークから射影変換を求め、斜めから撮った写真を正面化します。
4. マス境界ごとにインク量を積分し、大津の方法でしきい値を自動決定します。

塗った壁は罫線よりインク量が桁違いに大きいため、5マスごとの太い罫線とも確実に区別できます。

## プライバシー

画像処理はすべてブラウザ内で完結します。写真が外部に送信されることはありません。
コードにネットワーク通信は含まれていません（表示フォントの取得を除く）。

## 動作環境

Chrome / Safari / Edge / Firefox の最新版。オフラインでも動作します
（その場合は書体が標準フォントに変わりますが、機能は同じです）。
